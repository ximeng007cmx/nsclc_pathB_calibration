# TME calibration of published NSCLC prognostic signatures (pathB)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23537008.svg)](https://doi.org/10.5281/zenodo.23537008)

Code, registries and result tables for:

> **Immune and stromal content does not explain the effect sizes of published inflammation- and metabolism-related prognostic signatures in non-small cell lung cancer: a calibration study of 49 signatures with positive and negative controls**
> (manuscript draft v1, revision 07; target journal: *Cancer Medicine*)

49 published inflammation-, metabolism- and immune-related prognostic signatures (NSCLC) were assembled in four pre-registered waves under rules fixed before analysis, scored in TCGA-LUAD (n = 482, 177 deaths), and re-estimated after adjustment for tumour purity and immune/stromal content (ESTIMATE). Attenuation is quantified as `A = 1 − β_M3/β_M1` on the log-hazard scale, with three control axes (lymphocyte positive control, neutrophil and nutrition/liver-derived negative controls), a per-signature random-panel null (200 draws), two external directional-replication cohorts (GSE68465, GSE31210), two alternative endpoints (PFI, DSS) and a TCGA-LUSC histology check.

Every analysis step is hashed and locked before downstream use (`work/LOCK.txt`); every number in the manuscript is generated by scripts that read the result tables directly (`tools/25_reconcile_manuscript.py`, 146 checks); all 58 references were verified against Europe PMC + CrossRef (`manuscript/references_verified.md`).

## Data sources

- **TCGA-LUAD / TCGA-LUSC**: expression (log2 FPKM) and clinical data from TCGA / TCGA-CDR (Liu et al., Cell 2018, PMID 29625055); ESTIMATE scores per Yoshihara et al., Nat Commun 2013 (PMID 24113773).
- **GSE68465** (Director's Challenge, n = 439 analysed) and **GSE31210** (Japanese LUAD, n = 226 analysed): ArrayExpress mirrors of the GEO series (EBI BioStudies), as archived in the companion `pathA` pipeline.
- **PubMed Central full texts**: `work/xml/` (open-access; used for verifiable gene-list extraction, wave W2/W3).

## Reproduction

1. **Environment**: R 4.6.1 (`data.table`, `survival`, `GSVA`, `reshape2`), Python 3.13 (`openpyxl`, `markdown`).
2. Place `pa_data.rds` at `../pathA/work/pa_data.rds` (or adjust the `PA` constant at the top of each `R/` script).
3. Run `R/` scripts in numeric order (`00` … `24`), then the `tools/` scripts in numeric order (`05` … `29`). Bootstrap seed: `20261020`.
4. Verify: `tools/25_reconcile_manuscript.py` re-checks every number in the manuscript against `results/*.tsv` (146 checks; expected 145 pass + 1 manual-review item); `tools/28_binomial_test.py` re-derives the §3.2 exact binomial P value (0.8601) against `results/binomial_direction.tsv`.
